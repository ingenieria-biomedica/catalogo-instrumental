Fresas

Utilizadas para la talla protésica y la odontosección. El código de colores define la granulometría: Verde (Grueso), Azul (Medio), Rojo (Fino) y Amarillo (Extrafino).

Esféricas (Serie BR)
Cónicas Punta Redonda (Serie TR)
Troncocónicas Punta Plana (Serie TF)
Llama o Balón (Serie FO)
  • Esféricas (Serie BR): Empleadas para el acceso cavitario, eliminación de tejido carioso y creación de nichos de retención.
  • Cónicas Punta Redonda (Serie TR): Fundamentales en prótesis fija para realizar preparaciones extracoronarias (tallado de pilares) con una línea de terminación tipo chaflán.
  • Troncocónicas Punta Plana (Serie TF): Utilizadas para generar paredes con una convergencia oclusal específica y hombros definidos en preparaciones para coronas cerámicas.
  • Llama o Balón (Serie FO): Específicas para el ajuste de la morfología funcional en las caras palatinas de piezas anteriores o para el ajuste oclusal.
